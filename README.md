# Young Descendant of Țepeș
# 采佩什的年幼末裔

一个以《东方Project》角色蕾米莉亚·斯卡蕾特为主角的《欧陆风云IV》架空历史 Mod。
当红魔馆的大小姐来到十五世纪的瓦拉几亚，穿刺公的故乡将迎来怎样的命运？

## 当前版本
- Mod版本：v0.1.1
- 实测游戏版本：EU4 1.37.5
- 当前主要实装：蕾米莉亚强硬路线
- 开发状态：持续更新中
- 要求全dlc与汉化包开启，建议关闭其他mod，兼容性未验证
